Agentflow turns "just start coding" into a signed-off pipeline that any coding agent can follow, on any harness, without losing its memory between sessions.

It was built after studying the strongest workflow frameworks available — superpowers, Spec Kit, BMAD, Taskmaster, Agent OS — keeping their proven discipline and fixing the three problems none of them solve.

The pipeline has six stages. Stage one, spec, refuses to build anything until the human approves a written spec drawn through one question at a time. Stage two, plan, produces the architecture and bite-sized tasks an executor who has never seen the repo could follow. Stage three, task contracts, turns each task into a dispatchable unit with exact files, typed interfaces, machine-checkable done-when criteria, and stop-if conditions that make silent scope creep visible. Stage four, execute, runs the contracts under test-driven development: every test watched failing before code exists, the whole suite green before a task is ledgered, the cheapest model for mechanical work and the most capable model for the final branch review. Stage five, review, grades findings by their effect on a real user, forces one verified fix pass, defers minor items to the ledger, and lets the agent push back on a wrong reviewer with technical reasoning. Stage six, finish, presents the menu — merge, pull request, or keep — verifies the full suite on the merged tree, cleans the worktree, and archives every ruling.

Around the pipeline sit the meta skills. A bootstrap skill routes every conversation and forces the agent to check for skills before responding, even to clarifying questions. Verification-before-completion makes every success claim show fresh evidence. Systematic debugging hunts root causes through four phases and stops after three failed fixes, because that pattern means the architecture, not the hypothesis, is wrong. A writing-skills skill enforces test-first authoring for the skill library itself. A diagnosing skill reconstructs any failed session with evidence drawn from the ledger and git history.

Two ideas make it unlike anything published. First, the ledger: a single committed markdown file recording every gate, ruling, deferred minor, and completed task with its test evidence. Because it is committed, git clean cannot destroy it, a new session can trust it, and compaction costs context but never state. Second, the compiler: one manifest emits plugin manifests for Claude Code, Codex, Cursor, and the cross-runtime AGENTS.md alias, with validation tests that reject malformed skills and manifests. Supporting harnesses becomes five generated files, never five hand-maintained directories.

The human sees only decisions needing a signature: a spec to approve, a plan to review, one question when something is theirs to decide, and the final report lists every ruling made for them and every deferred defect.

Everything binds to team conventions: one conventions file, stamped per project, that every stage inherits as its implicit contract. Zero telemetry by design. MIT licensed, with a NOTICE file documenting the MIT ancestry of the structure and two retained phrasings.

Install takes one line per harness, or npx plus agentflow init for everything else.
