Agentflow turns "just start coding" into a signed-off pipeline that any coding agent can follow, on any harness, without losing its memory between sessions. It keeps the proven discipline of superpowers, Spec Kit, BMAD, Taskmaster, and Agent OS, fixing what none solve.

The pipeline has six stages. Spec refuses to build until the human approves a written spec drawn one question at a time. Plan produces bite-sized tasks an executor who has never seen the repo could follow. Task contracts turn each task into a dispatchable unit with exact files, typed interfaces, machine-checkable done-when criteria, and stop-if conditions that expose scope creep. Execute runs the contracts under test-driven development: tests watched failing before code exists, whole suite green before a task is ledgered, cheapest model for mechanical work, most capable at the final review. Review grades findings by real-user effect, forces one verified fix pass, defers minors, and lets the agent push back on a wrong reviewer. Finish offers merge, pull request, or keep, verifies the merged tree, and archives every ruling.

Meta skills wrap the pipeline: a bootstrap routes every turn, forcing skill checks; verification makes every success claim show fresh evidence; debugging hunts root causes in four phases and stops after three failed fixes; writing-skills keeps the skill library test-first; diagnosing reconstructs failed sessions from ledger and git evidence.

Two ideas are unique. The ledger: one committed markdown file recording every gate, ruling, and completed task with test evidence — committed, so git clean cannot destroy it, and compaction costs context, never state. The compiler: one manifest emits manifests for Claude Code, Codex, Cursor, and the AGENTS.md cross-runtime alias, with tests rejecting malformed input — five generated files, never five hand-maintained directories.

Everything binds to one per-project conventions file every stage inherits. The human sees only decisions needing a signature: a spec to approve, a plan to review, one question when something is theirs, and the final report listing every ruling and deferred defect. Zero telemetry. MIT licensed; a NOTICE file documents the structure's ancestry. Install: one line per harness, or npx plus agentflow init for everything else.
